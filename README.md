# Kerdz releases

Installeurs Windows de [Kerdz](https://github.com/dhadjhenni/kerdz), une app de flashcards avec répétition espacée FSRS.

Téléchargez `Kerdz_x.y.z_x64-setup.exe` dans la [dernière release](https://github.com/dhadjhenni/kerdz-releases/releases/latest). Une fois installé, Kerdz se met à jour tout seul.

Ce dépôt ne contient que les releases ; elles sont publiées automatiquement.
